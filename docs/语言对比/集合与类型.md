# 集合与类型 —— C++ / C# / TypeScript 对比

> 主题：集合（Set）用法、取长度、`const`/只读语义、容器与数值类型等，在 C++ / C# / TypeScript 三种语言里的差异。
> 背景：同一道题（[2913. 子数组不同元素数目的平方和 I](https://leetcode.cn/problems/sum-of-counts/)）在三种语言里实现时，暴露出的一些语言差异。
> 姊妹篇：[`字符串遍历与最值.md`](字符串遍历与最值.md)（Python / TypeScript / C#）。

---

## 一、集合（Set）对比

同一件事——"往一个集合里放数、去重、数个数"——三种语言写法差别不小：

| 操作 | C++ `std::set<int>` | C# `HashSet<int>` | TypeScript `Set<number>` |
|------|---------------------|-------------------|--------------------------|
| 头文件/命名空间 | `#include <set>` | `using System.Collections.Generic;` | 内置，无需引入 |
| 新建 | `set<int> s;` | `var s = new HashSet<int>();` | `const s = new Set<number>();` |
| 插入 | `s.insert(x)` → `pair<iterator,bool>` | `s.Add(x)` → `bool` | `s.add(x)` → **`Set` 自身**（链式） |
| 大小 | `s.size()` → `size_t` | `s.Count` | `s.size` |
| 查找 | `s.count(x)`（0/1） | `s.Contains(x)` | `s.has(x)` |
| 删除 | `s.erase(x)` | `s.Remove(x)` → `bool` | `s.delete(x)` → `bool` |
| 清空 | `s.clear()` | `s.Clear()` | `s.clear()` |
| 遍历 | `for (auto x : s)` | `foreach (var x in s)` | `for (const x of s)` |
| 顺序 | **按值排序**（红黑树） | 无序 | **按插入顺序** |
| 复杂度 | O(log n) | 均摊 O(1) | 均摊 O(1) |
| 有序版 | `std::set` 本身就是 | `SortedSet<T>` | 无内置（需自己用数组/结构） |
| 无序/哈希版 | `std::unordered_set` | `HashSet<T>` | `Set<T>` |

**几个关键差异：**

- **`add` 的返回值**：C++ 返回 `pair`（第二项表示是否新增）、C# 返回 `bool`、**TS 返回 Set 自身**。所以"这次是不是新加的"这件事，TS 里不能靠返回值判断。
- **大小**：C++ 是方法 `size()`；C#/TS 是**属性** `Count` / `size`（都不带括号）。TS 里写成 `s.size()` 会报 "not a function"。
- **有序性**：C++ `set` 默认排好序；TS `Set` 保持插入顺序；C# `HashSet` 不保证顺序——只有 `SortedSet<T>` 才有序。

## 二、取"长度 / 大小"

| 对象 | C++ | C# | TypeScript |
|------|-----|----|-----------|
| 动态数组 | `vec.size()` | `List<T>` → `.Count` | `T[]` → `.length` |
| 定长数组 | `arr[N]` / `std::array` → `.size()` | `T[]` → **`.Length`** | `T[]` → `.length` |
| 集合 | `set.size()` | `HashSet<T>` → `.Count` | `Set<T>` → `.size` |
| 字典 | `map.size()` | `Dictionary<K,V>` → `.Count` | `Map<K,V>` → `.size` |
| 字符串 | `str.size()` / `.length()` | `str.Length` | `str.length` |
| 惰性序列 | — | `IEnumerable<T>` → `.Count()`（LINQ，会枚举） | `Iterable<T>` → 需 `[...s].length` |

**记忆点：**

- C++：**方法**，统一 `size()`（返回 `size_t`，无符号！注意 `size() - 1` 可能下溢成超大正数）。
- C#：数组用 **`.Length`**，集合用 **`.Count`**（都是属性）。
- TS：数组用 **`.length`**，Set/Map 用 **`.size`**（都是属性）。

## 三、变量声明与 const / 只读语义 ⭐

这是最容易把 C++/C# 思维带偏的地方。

| 语言 | 声明关键字 | `const` 的含义 | 能改对象内容吗 |
|------|-----------|----------------|----------------|
| C++ | `int x; auto y = ...; const T z;` | **真正的编译期只读**，不可修改 | ❌（改了编译不过） |
| C# | `var` / `const` / `readonly` | `const` = 编译期常量（只能是字面量等）；`readonly` = 运行期只读字段 | `const` 对象 ❌；`readonly` 字段指向的对象 ✅ 仍可改 |
| TypeScript | `const` / `let` / `var`（+ 类型级 `readonly`） | **只禁止"重新赋值"**，不禁止"原地修改" | ✅ 可以 |

### TS 的 `const` 到底锁了什么

```ts
const seen = new Set<number>();
seen.add(1);      // ✅ 合法：修改对象内容（mutate）
seen = new Set(); // ❌ 编译错误：不能给 const 变量重新赋值（reassign）
```

> **`const` 锁的是"变量名指向哪个对象"，不是"对象的内容"。** JS/TS 里 `const` ≠ 不可变。
> 顺带：`const` 有**块级作用域**，写在循环体里每轮都是全新的对象。

### 想要"真不可变"怎么办

- **TS**：类型层面用 `ReadonlySet<T>` / `ReadonlyArray<T>` / `readonly` 属性 / `as const`。
  ```ts
  const ro: ReadonlySet<number> = seen;
  ro.has(1);   // ✅
  ro.add(2);   // ❌ ReadonlySet 上不存在 add（编译期限制）
  ```
- **C#**：用 `IReadOnlyList<T>`、`IReadOnlyDictionary<K,V>` 这类只读接口表达意图；`readonly` 字段只是"引用不变"。
- **C++**：`const` 是真只读，`const T&` 传参防止被修改。

## 四、循环与遍历

| 需求 | C++ | C# | TypeScript |
|------|-----|----|-----------|
| 计数循环 | `for (int i=0;i<n;i++)` | `for (int i=0;i<n;i++)` | `for (let i=0;i<n;i++)` |
| 遍历元素 | `for (auto x : v)` | `foreach (var x in v)` | `for (const x of v)` |
| 遍历下标 | 同上 | 同上 | `for...in`（⚠️ 拿到的是字符串下标，别用于数组取值） |
| 带下标遍历 | 手写 / `std::views::enumerate`(C++23) | 手写 | `arr.forEach((x,i)=>...)` / `arr.entries()` |

**注意**：TS 的 `for...in` 遍历的是**键（index 字符串）**，不是值；数组取值请用 `for...of`。

## 五、LeetCode 函数签名与类型

同一道题的入口签名：

```cpp
// C++
int sumCounts(vector<int>& nums) { ... }
```

```csharp
// C#
public int SumCounts(IList<int> nums) { ... }
```

```ts
// TypeScript
function sumCounts(nums: number[]): number { ... }
```

差异点：

- 参数类型：C++ 常用 `vector<int>&`；C# 用 `IList<int>`（或 `int[]`）；TS 用 `number[]`。
- 命名：C++ 小驼峰、C# **大驼峰**（`SumCounts`）、TS 小驼峰（`sumCounts`）。
- 返回类型写在各自位置：C++/C# 在函数名前，TS 在参数后 `: number`。

## 六、泛型的写法

| 语言 | 集合声明 |
|------|---------|
| C++ | `set<int> s;` / `vector<int> v;`（模板） |
| C# | `var s = new HashSet<int>();` / `SortedSet<int>` |
| TS | `const s = new Set<number>();`（尖括号 + 类型） |

TS 里若能让编译器推断，也可以省略：`new Set()`，但显式写 `<number>` 更清晰、也更安全。

## 七、数值类型、溢出与取模

| | C++ | C# | TypeScript |
|--|-----|----|-----------|
| 常用整数 | `int`(32位) / `long long`(64位) | `int`(Int32) / `long`(Int64) | `number`（**float64**，无整数类型） |
| 溢出 | 有符号溢出是 UB；需换 `long long` | 默认不检查（除非 `checked`） | 超过 2⁵³−1 丢精度，需 `bigint` |
| 取模 | `a % b` | `a % b` | `a % b`（JS 语义） |

**要点：**

- **C++**：两个 `int` 相乘可能溢出，用 `1LL * a * b` 提升到 64 位。
- **C#**：`int` 溢出会回绕，乘积大时改用 `long`。
- **TS/JS**：所有数字都是双精度浮点，**安全整数范围是 ±(2⁵³−1)**（约 9×10¹⁵）。本题规模（n≤100，答案 ~10⁷）绰绰有余；但真要处理大整数得用 `bigint`。

> 本题（2913 简单版）三种语言都**不需要取模**，`int` / `number` 都不会溢出。它的加强版 2916（n≤10⁵）才需要取模 + 换算法。

## 八、常用容器对照表

| 用途 | C++ | C# | TypeScript |
|------|-----|----|-----------|
| 动态数组 | `std::vector<T>` | `List<T>` | `T[]` |
| 有序集合 | `std::set<T>` | `SortedSet<T>` | 无内置 |
| 哈希集合 | `std::unordered_set<T>` | `HashSet<T>` | `Set<T>` |
| 有序映射 | `std::map<K,V>` | `SortedDictionary<K,V>` | 无内置 |
| 哈希映射 | `std::unordered_map<K,V>` | `Dictionary<K,V>` | `Map<K,V>` |
| 栈 | `std::stack<T>` | `Stack<T>` | `T[]` + `push/pop` |
| 队列 | `std::queue<T>` | `Queue<T>` | `T[]` + `shift/push` |
| 优先队列 | `std::priority_queue<T>` | `PriorityQueue<T,P>`(.NET 6+) | 无内置 |

（C# 的 `List<T>`、`Dictionary<K,V>` 需要 `using System.Collections.Generic;`。）

## 九、易踩坑清单

1. **`const` 不等于不可变**：TS 的 `const` 只防重新赋值；要类型级只读用 `ReadonlySet`/`ReadonlyArray`。
2. **属性 vs 方法**：C++ 统一 `size()`；C# 是 `Count`/`Length`，TS 是 `size`/`length` —— 后两者**不加括号**。
3. **`add` 返回值**：C++ `pair`、C# `bool`、**TS 返回 Set 自身**。
4. **数组长度怎么取**：C# 数组 `.Length`、`List` `.Count`；TS 数组 `.length`、`Set` `.size` —— 别串。
5. **TS 的 `for...in` 给的是下标（字符串）**，数组遍历用 `for...of`。
6. **C++ `size()` 是无符号**：`size() - 1` 在为空时会下溢。
7. **整数溢出**：C++/C# 要主动换类型；TS 数字是浮点、有 2⁵³ 精度上限。
8. **命名风格**：C# 方法名用**大驼峰**，C++/TS 用小驼峰。

## 附：本次 2913 的核心思路（三语言通用）

> 枚举所有子数组时，**固定左端点 `i`，右端点 `j` 从 `i` 向右生长**；用一个集合在 `j` 前进时**增量维护**不同元素，累加 `size²`。
> 复杂度从"每个子数组重建集合"的 O(n³)（按长度三层枚举）降到 **O(n²)**。
