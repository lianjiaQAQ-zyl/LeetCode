# 模运算 —— 取模、溢出与组合数

> 主题：取模（mod）的基本性质、为什么必须每步取模、类型选择与溢出、逆元与组合数取模。
> 背景：[1569. 将子数组重新排序得到同一个二叉搜索树的方案数](https://leetcode.cn/problems/number-of-ways-to-reorder-array-to-get-same-bst/) 与 [2897. 对数组执行操作使平方和最大](https://leetcode.cn/problems/apply-operations-on-array-to-maximize-sum-of-squares/) 中反复出现的坑。
> 示例语言：C++（其余语言的差异见文末）。

---

## 一、取模是什么

`a mod m` 就是 `a` 除以 `m` 的**余数**：

```cpp
7 % 3   // 1
-7 % 3  // -1   ← C++/C#/JS 会保留被除数的符号
```

数学上通常把结果规范到 `[0, m)`。编程题里说"答案对 1e9+7 取模"，就是要求最终结果落在 `[0, 1e9+6]`。

**为什么要取模？** 两个原因：

1. **答案太大**。方案数、路径数、子序列数等经常是天文数字，`long long` 也装不下。
2. **题目约定**。1e9+7 是质数，方便做除法（见第六节），几乎所有竞赛题都用它。

---

## 二、四条基本性质

设 `a`、`b` 是任意整数，`m` 是模数，则：

| 运算 | 性质 | 说明 |
|------|------|------|
| 加法 | `(a + b) % m == ((a % m) + (b % m)) % m` | 可以先各自取模 |
| 减法 | `(a - b) % m == ((a % m) - (b % m) + m) % m` | **必须 +m 防负数** |
| 乘法 | `(a * b) % m == ((a % m) * (b % m)) % m` | 可以先各自取模 |
| 除法 | `(a / b) % m ≠ ((a % m) / (b % m)) % m` | **不成立**，要用逆元 |

记忆方式：**加减乘**都可以把取模"分"到每一步，**除法不行**。

这条性质是"每步取模"的理论依据：既然 `(a*b) % m == ((a%m)*(b%m)) % m`，那么在任何一步先取模都不影响最终答案。

---

## 三、为什么不能"最后再取模"

假设你要算 `C(999, 500)`（1569 里就会出现）：

- 真实值约 **10²⁹⁸**
- `long long` 上限约 **9.22 × 10¹⁸**

差了近 300 个数量级。**没有任何内置整数类型装得下**，所以不存在"先算精确值、最后再取模"这个选项。

更糟的是：`long long` 溢出在 C++ 里是**未定义行为**（signed overflow），溢出的残值本身就不确定，再对它取模毫无意义。

**结论：每一步乘完立刻取模。**

```cpp
// 错误：想最后再取模
long long ans = C[n-1][L];        // 这一步就没法存下真实值
ans = ans * waysLeft * waysRight;
return ans % MOD;

// 正确：每乘一次取一次模
long long ans = C[n-1][L];
ans = ans * waysLeft % MOD;
ans = ans * waysRight % MOD;
return ans;
```

## 四、类型：int 还是 long long

这是最容易踩的坑，核心规则只有一条：

> **溢出取决于操作数的类型，不取决于你赋值给谁。**

```cpp
int a = 1e9, b = 1e9;
long long c = a * b;          // ✗ a*b 先在 int 里算，溢出后才赋值给 c
long long d = 1LL * a * b;    // ✓ 1LL 把表达式提升为 long long
```

`1LL * a` 让 `a` 先转成 `long long`，后面的乘法就都在 `long long` 里进行。

### 四种运算的安全边界

| 运算 | 两个操作数都 < 1e9+7 时 | 是否安全（int） |
|------|------------------------|-----------------|
| 加法 | 和 < 2.000000014×10⁹ | ✅ 安全（INT_MAX ≈ 2.147×10⁹） |
| 减法 | 差的绝对值 < 1e9+7 | ✅ 安全（但可能是负数） |
| 乘法 | 积 < 1.000000014×10¹⁸ | ❌ **溢出** |
| 除法 | — | ❌ 不成立（见第六节） |

所以杨辉三角里的**加法**用 `int` 没问题：

```cpp
C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;   // int 加法，安全
```

但**乘法**必须用 `long long`：

```cpp
ways = ways * other % MOD;   // ways 和 other 都 < 1e9，乘积约 1e18
                             // 用 int 会溢出，用 long long 刚好
```

### 建议

- 涉及取模的**乘法**，统一用 `long long`；
- 或者每次乘法前显式写 `1LL *`；
- 只有确认是加法/减法且值域清楚时，才放心用 `int`。

### 顺手一个坑：`1e9 + 7` 是浮点数

```cpp
const int MOD = 1e9 + 7;          // 能编译，值是 1000000007，但 1e9 本身是 double
const int MOD = 1'000'000'007;    // 推荐：纯整数，可读性好
```

## 五、减法：防止负数

C++/C#/Java/JS 的 `%` 会保留被除数的符号：

```cpp
(0 - 1) % 1000000007   // -1，不是 1000000006
(-5) % 3               // -2，不是 1
```

所以减法取模的标准写法是：

```cpp
ans = (a - b + MOD) % MOD;          // 两数都已在 [0, MOD) 时够用
ans = ((a - b) % MOD + MOD) % MOD;  // 更通用的写法
```

典型场景：1569 里要减掉"原数组本身"这一种方案。

```cpp
return (int)((dfs(nums) - 1 + MOD) % MOD);
```

如果漏了 `+ MOD`，当 `dfs` 恰好返回 0 时，结果会变成 `-1`。

## 六、除法与逆元

`(a / b) % m` **不能**拆成 `((a % m) / (b % m)) % m`。例如：

```
(6 / 2) % 5 = 3
((6 % 5) / (2 % 5)) % 5 = (1 / 2) % 5   ← 没有意义
```

正确做法是把"除以 b"换成"乘以 b 的逆元"。

### 费马小定理

当 `m` 是**质数**、`a` 不是 `m` 的倍数时：

```
a^(m-2) ≡ a^(-1)  (mod m)
```

于是 `a / b ≡ a * b^(m-2)  (mod m)`。

### 快速幂（求逆元的基础）

```cpp
long long modPow(long long a, long long e, long long mod) {
    long long r = 1 % mod;
    a %= mod;
    while (e > 0) {
        if (e & 1) r = r * a % mod;
        a = a * a % mod;
        e >>= 1;
    }
    return r;
}

long long inv(long long a, long long mod) {
    return modPow(a, mod - 2, mod);   // 要求 mod 是质数
}
```

时间复杂度 O(log m)。

### 前提条件

- `m` 必须是**质数**（1e9+7 满足）；
- `a` 不能被 `m` 整除（若 `n < 1e9+7`，阶乘一定满足）；
- 否则逆元不存在，费马小定理失效。

## 七、组合数取模的两种预处理

### 方法一：杨辉三角（O(n²) 时间，适合 n ≲ 5000）

```cpp
const int MOD = 1'000'000'007;
vector<vector<int>> C(n, vector<int>(n, 0));

for (int i = 0; i < n; ++i) {
    C[i][0] = C[i][i] = 1;
    for (int j = 1; j < i; ++j) {
        // 加法：两个加数 < MOD，和 < 2e9 < INT_MAX，安全
        C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
    }
}
// 查询：C[a][b]
```

⚠️ 别把 `long long C[1005][1005]` 写成函数局部数组或类的普通成员——约 8MB，容易栈溢出。用 `vector`（堆上）或 `static` 成员。

### 方法二：阶乘 + 逆阶乘（O(n) 预处理，适合 n 很大）

```cpp
const long long MOD = 1'000'000'007;
vector<long long> fac(n + 1), invfac(n + 1);

fac[0] = 1;
for (int i = 1; i <= n; ++i)
    fac[i] = fac[i-1] * i % MOD;

invfac[n] = modPow(fac[n], MOD - 2, MOD);
for (int i = n; i >= 1; --i)
    invfac[i-1] = invfac[i] * i % MOD;

auto comb = [&](int a, int b) -> long long {
    if (b < 0 || b > a) return 0;
    return fac[a] * invfac[b] % MOD * invfac[a-b] % MOD;
};
```

原理：`C(n,k) = n! / (k!(n-k)!)`，把除法换成乘逆元。

### 怎么选

| | 杨辉三角 | 阶乘 + 逆元 |
|---|---|---|
| 预处理 | O(n²) | O(n) |
| 单次查询 | O(1) | O(1) |
| 空间 | O(n²) | O(n) |
| 适用 n | ≲ 5000 | 很大（< MOD） |
| 代码 | 短，不易错 | 多一个快速幂 |

n ≤ 1000（如 1569）用杨辉三角最省事。

## 八、负数的取模：跨语言差异 ⭐

同一个表达式，不同语言结果可能不同：

| 表达式 | C++ | C# | Java | Python | JS / TS |
|--------|-----|----|------|--------|---------|
| `-7 % 3` | `-1` | `-1` | `-1` | `2` | `-1` |
| `7 % -3` | `1` | `1` | `1` | `-2` | `1` |

- **C++ / C# / Java / JS / TS**：余数符号跟随**被除数**（截断除法）。
- **Python**：余数符号跟随**除数**（向下取整除法），结果总落在 `[0, |m|)`。

所以：

- 在 Python 里 `(a - b) % m` 天然非负，可以少写 `+ m`；
- 在 C++/C#/TS 里**必须**手动 `+ MOD` 再取模；
- 这也是移植代码时最容易出错的地方之一。

## 九、常见坑清单

1. **最后才取模** —— 真实值早就溢出，溢出残值取模是垃圾。
2. **`int * int` 溢出** —— 赋值给 `long long` 发生在乘法之后，救不回来。
3. **减法出负数** —— `(a - b) % MOD` 可能为负，要 `+ MOD`。
4. **只给因子取模，不给乘积取模** —— `C * (x % MOD)` 仍然是 int 乘法，照样溢出。
5. **`1e9 + 7` 当整数常量写** —— 它是 `double`，建议写 `1'000'000'007`。
6. **对负数直接 `%`** —— 跨语言行为不同，见第八节。
7. **对大数组开在栈上** —— `long long C[1005][1005]` 约 8MB，容易爆栈。
8. **逆元用在非质数模数上** —— 费马小定理要求模数是质数。
9. **取模后比较大小** —— 取模会破坏大小关系，不能在取模后判断"谁更大"。
10. **`size()` 是无符号数** —— `s.size() - 1` 在 `s` 为空时会下溢成超大正数（顺带一提，不属于取模但常一起出现）。

## 十、例题对照

### 1569. 同一棵 BST 的方案数

递推：

```
ways(集合) = C(n-1, L) × ways(左) × ways(右)
```

取模写法：

```cpp
long long ways = C[n - 1][left.size()];   // 已经取过模
ways = ways * dfs(left)  % MOD;           // 乘完立刻取模
ways = ways * dfs(right) % MOD;
return ways;

// 最外层：减掉原数组本身
return (int)((dfs(nums) - 1 + MOD) % MOD);
```

### 2897. 平方和最大

每个数平方后可能到 `1e18`，必须在乘法前提升类型：

```cpp
// 错误：两个 int 先乘，溢出后才赋给 long long
long long t = (num % MOD) * (num % MOD) % MOD;

// 正确：先提升为 long long
long long t = 1LL * num * num % MOD;
```

同理，`2^i` 要写 `1LL << i`，而不是 `1 << i`（i 较大时 int 会溢出）。

## 十一、速查

```cpp
constexpr int MOD = 1'000'000'007;   // 1e9+7，质数

// 加法
ans = (a + b) % MOD;

// 减法（防负数）
ans = (a - b + MOD) % MOD;

// 乘法（必须 long long）
ans = 1LL * a * b % MOD;

// 快速幂
long long r = 1;
while (e) { if (e & 1) r = r * a % MOD; a = a * a % MOD; e >>= 1; }

// 逆元（mod 为质数）
inv = modPow(a, MOD - 2, MOD);

// 组合数（杨辉三角）
C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
```

**一句话总结：加减乘可以拆开逐步取模，除法要换成乘逆元；乘法一律用 `long long`；减法记得 `+ MOD`。**
